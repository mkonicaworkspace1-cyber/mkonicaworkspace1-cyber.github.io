# Marjana — Skill Portfolio

A static GitHub Pages portfolio based on the supplied visual draft.

## Replace later

- `assets/images/profile-placeholder.svg` → your profile photo
- `assets/images/*placeholder.svg` → final project/report images
- `assets/pdfs/Marjana_CV.pdf` → your CV
- other files in `assets/pdfs/` → your final PDFs
- YouTube links in `statistics.html` and `presentations.html` → your own videos
- social/contact links in `index.html`

The site uses relative paths so it can work as a GitHub Pages project site as well as locally.
