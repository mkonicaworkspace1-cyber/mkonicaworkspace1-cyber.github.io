# Marjana Research Portfolio

A minimalist research portfolio designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Visit `https://YOURUSERNAME.github.io`.

GitHub Pages hosts static HTML, CSS and JavaScript directly from a repository.

## Easy edits

- Main text and sections: `index.html`
- Design/colors/layout: `style.css`
- Theme toggle and interactions: `script.js`
- Replace `mailto:your.email@example.com` with your email.
- Replace `#` on the six portfolio cards with your project links/PDFs/Drive links.

No framework or build process is required.
